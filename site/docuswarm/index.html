How it works

1. Scan the source

Every Markdown/MDX page in your docs repo: internal links, cross-page anchors, images, code-block syntax (Python, JSON, YAML, TOML), unclosed fences and leftover TODOs.

2. Confirm on the live site

Each link is checked against your published pages, using your docs platform's real anchor IDs. Findings that work live are dropped, so the report holds only real breaks.

3. Fix and guard

One PR with the unambiguous fixes, grouped by type so it reviews quickly, plus a GitHub Action that fails only PRs that introduce new breaks. The existing backlog never blocks you.

FAQ

Can't we just run our docs platform's link checker?

You can, and it's worth turning on. Some checks, such as anchor checking, are opt-in, which is how these breaks slip through. What we add: each finding confirmed on the live site, the fixes done as a PR, code-sample checks, and a CI gate that only fails on new breaks.

What access do you need?

For public docs, none: the repo and the published site are enough. For private docs, read access to the docs repository.

Do you rewrite our docs?

No. The packages cover links, anchors, images and code-sample syntax, plus a manual read of your top 10 pages. Content and product design stay yours.

How do I pay?

By invoice after you accept the quote, by card or bank transfer. Prices are in US dollars.
